# 图件制作与论文写作路线图 v0.1

> 本指南按 PAPER 当前数据结构设计。它从数据核对开始，逐步到制图、结果撰写和投稿前检查。第一次学习时，先完成每一步的检查点，再做下一步。

## 一、软件怎么选

| 工作 | 建议软件 | 适用范围 |
|---|---|---|
| 数据清理、重复检查、重算统计 | **Python 3.12 + pandas、NumPy、SciPy** | 仓库已有脚本是 Python；先沿用同一分析链，便于复现和排查数据问题。 |
| 剂量–响应模型 | **Python/SciPy** 或 **R 的 drc** | 4PL 等剂量响应拟合。drc 提供剂量–响应模型拟合与后续分析功能；R 路线适合统一做模型和作图。 |
| 最终发表图 | **Python/Matplotlib** 或 **R/ggplot2** | 可生成小倍数图、误差区间、热图和矢量图。重要的是脚本可复现，而不是软件品牌。 |
| CATA 对应分析 | **RStudio + FactoMineR** | FactoMineR 提供对应分析（CA）；样品为行、属性频数为列。 |
| 手工查看/复核 | Excel | 适合检查表头、编码、样品表；不要用它替代模型分析或最终统计绘图。 |
| 面板拼版 | Inkscape / Illustrator | 只用于排列已完成的子图、统一字体和面板字母；不要在里面移动、删改数据点。 |
| 快速试画 | GraphPad Prism | 适合快速查看单个剂量响应；复杂的自助法区间、数据清理和可复现多图流程仍建议用脚本。 |

**推荐学习路径：**先在 Python 中复现现有图和质量检查；随后用 RStudio 学习 CATA 对应分析。每一个图只保留一个“唯一可信数据表”和一段可重跑脚本。R 的 drc、FactoMineR 和 ggplot2 官方/CRAN 文档可作为软件操作参考：drc（https://CRAN.R-project.org/package=drc）、FactoMineR CA（https://search.r-project.org/CRAN/refmans/FactoMineR/help/CA.html）、ggplot2（https://CRAN.R-project.org/package=ggplot2）。

## 二、先把研究问题和数据边界定清楚

### 第 1 步：区分两类响应

1. **单体样品：**有 0–12 强度评分，可画浓度–强度曲线。
2. **混合样品：**当前表里是 CATA 勾选频率，没有混合强度评分。
3. 因此不能把 CATA 频率当作强度，也不能用当前混合数据得出强度协同或经典 σ–τ 结论。

**检查点：**在分析数据字典中为每列标出单位、含义、层级（评审员/样品/重复轮次）和缺失规则。

### 第 2 步：数据质量冻结

先用仓库里的清理脚本和 QC 表核查：

- 每条数据的样品、评审员、化合物和浓度能否唯一对应；
- 苯乙醇 C1–C6 的两轮数据是否确属独立轮次；
- 65 条混合样与 2⁶ 设计表的样品数差异来自何处；
- 原始逐人数据与论文均值表不一致的 23 个浓度点；
- 浓度单位、量表边界和所有化合物中英文名。

把核对结果写入单独的 QC 表。数据冻结后再建模；修复前不覆盖原始文件。

## 三、四类图按什么顺序做

### 第 3 步：单体浓度–强度图（优先）

**图形：**小倍数剂量–响应图。每种化合物一个小面板，横轴为对数浓度，纵轴为强度；叠加逐人数据（可用轻微抖动）、每个浓度的均值和区间、4PL 拟合曲线和曲线不确定带。

**为什么有说服力：**读者能同时看见真实评分、曲线形状和模型在哪一段有数据支持。不要只展示 R² 或参数点估计。

**制作步骤：**

1. 整理成长表：compound、concentration、assessor、intensity、round。
2. 按实际观测浓度作图，横轴设 log10；原始数据仍用原单位存储。
3. 先画观测点和误差区间，再拟合候选模型。
4. 检查残差、收敛、上下平台和参数区间；没有平台或 EC50 超出观测范围时，标为弱识别或不报告。
5. 用评审员为单位做自助法重抽样，保留同一评审员对不同浓度的配对结构，计算曲线带与 EC50 区间。
6. 另做一张按 EC50 排序的森林图；区间异常或不可辨识的化合物单独标注。

**关键检查：**目前异丁酸乙酯的 EC50 置信区间下界高于点估计，必须先修正。Imax 超过 12 的拟合值是外推结果，不是可观察评分。

### 第 4 步：混合物 CATA 图谱

建议同时做两张互补图：

- **样品 × 属性频率热图：**颜色代表选择该属性的评审员比例。优点是直接、易解释，适合展示所有组合。
- **对应分析 CA 双标图：**样品点与属性点在同一感官空间中展示关联。CATA 频数矩阵常用于构建样品—属性图谱；可用 R 的 FactoMineR 执行 CA。已有方法研究比较过 CATA 感官空间的对应分析方案。genui{"citation":{"refs":["turn6search3","turn10view0"]}}

**制作步骤：**

1. 用原始逐人 CATA 记录形成“评审员 × 样品 × 属性”的 0/1 数据。
2. 核对每个样品的有效评审员数，再计算选择比例。
3. 先画频率热图，检查是否有全零/极低频属性。
4. 对样品 × 属性频数表做 CA；标出轴解释率、样品组别和属性名。
5. 检查稀有属性是否主导距离；必要时按预先制定的规则合并或放入补充材料。
6. 不要只凭图上点远近宣称显著差异；CA 是探索性空间图，需要配合统计和不确定性说明。

### 第 5 步：CATA 加和偏差图

**图形：**属性偏差点图/森林图。横轴为“实测选择比例 − 加和预测比例”，零线表示预测与实测一致；每点配一个以评审员为单位计算的区间。

**制作步骤：**

1. 按仓库中的预测式，逐个重算每个“二元混合 × 属性”的预测频率。
2. 计算偏差，并检查预测值是否因截断到 [0,1] 而大量堆在边界。
3. 以评审员为整组进行重抽样；每次重新计算基线、单体频率、预测值和偏差。
4. 画偏差与区间，按属性或混合物分面；正文只突出有稳定证据的结果。
5. 保留总体相关系数和 RMSE 作为描述性指标，但不要把 225 个配对点当成 225 个独立受试者计算显著性。

**用词边界：**当前数据最多支持“CATA 属性选择频率偏离/接近简单加和预测”。“协同”“掩蔽”应谨慎使用，更不能写成混合物强度效应。

### 第 6 步：品评员差异图

当前聚类结果不支持稳健的敏感者/不敏感者分组。更合适的主图是：

- 单体评分的逐人响应轨迹（淡灰线）；
- 面板总体曲线（彩色实线）；
- 总体不确定带；
- 必要时补一张品评员 × 化合物的响应热图。

完整聚类和双峰诊断可以放补充材料，作为检验“是否存在分组”的负结果。CATA 面板一致性分析可作为后续探索方向；CATATIS 等方法可评估整体一致性及评审员权重，但需要先确认原始 CATA 逐人数据结构。

## 四、英文论文怎么写

### Abstract（摘要）

用 4–6 句话交代：研究问题 → 数据/设计 → 核心方法 → 关键数值结果 → 结论边界。摘要不写没有重算的区间、显著性或因果机制。

### Materials and methods（实验材料与方法）

按可复现顺序写：化合物及纯度 → 溶剂/样品配制 → 浓度和样品设计 → 评审员 → 感官程序 → 数据清洗 → 统计模型 → 软件版本。缺少的信息用待查清单，不根据经验补写。

### Results（结果）

按图的顺序写，每段回答一个问题：

1. 数据纳入了多少人、样品和观测；
2. 单体剂量响应呈什么形状、参数区间如何；
3. CATA 频率与加和预测差多少；
4. 数据是否支持品评员分群。

先报告估计值、区间和图表位置；把原因解释留到 Discussion。对当前数据，225 个“混合物 × 属性”点是重复结构，不要据此直接报告独立样本 p 值。

### Discussion（讨论）

建议使用这个顺序：

1. 先用一段回答主要发现；
2. 与直接相关的剂量响应/CATA 原始研究比较，说明相同点和差异；
3. 解释可能机制，但用“可能”“与……一致”，不要从描述性图直接推断因果；
4. 单独说明强度与 CATA 不是同一响应；
5. 讨论量表地板/天花板、重复轮、样本数和数据表差异；
6. 最后提出下一步实验：对混合物直接采集强度或 RATA，覆盖更多中间浓度并保留逐人配对数据。

**文献检索与引用：**优先引用直接研究剂量–响应、CATA 方法、香气混合交互的原始研究；综述用于交代领域背景。每条引用都要支持紧邻的具体观点。不要堆砌“Q2 论文很多都这么做”，也不要把引言写成文献摘要列表。

## 五、当前稿件的优先级

1. **先解决数据问题：**轮次、混合设计 64/65 条、23 个均值差异、异丁酸乙酯 EC50 区间。
2. **再完成能提高证据强度的图：**剂量–响应小倍数图、CATA 频率热图/CA、加和偏差及评审员级区间。
3. **然后写结果：**只引用已冻结数据表中的数值。
4. **最后写 Discussion 和摘要：**让摘要与最终结果一致。
5. **确定目标期刊后再排版：**字号、图宽、文件格式和参考文献样式按期刊指南调整。
