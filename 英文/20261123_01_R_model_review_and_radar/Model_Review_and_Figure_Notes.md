# 单体强度曲线与毕设图形的核对说明

本次不按拟合外观筛选化合物。主图展示全部15种单体、93个浓度标签和1,674条评分；单体雷达图同样覆盖全部15种，混合雷达图覆盖全部65个样品。数据来自已确认修订的两份Excel，与PAPER仓库当前确认版本的文件逐字节一致。原始Excel未被本次工作修改。

## R模型的复核结果

旧R程序的四参数公式为：

I(C) = bottom + (top-bottom) * plogis[s * (log10(C)-log10(EC50))]

约束为0 <= bottom < top <= 12，0.05 <= s <= 10，log10(EC50)允许超出观测区间3个数量级。EC50对应估计上下平台之间的中点，不能不加说明地解释为“达到6分的浓度”；常规Hill指数为s/log(10)。

本次在R中使用另一优化算法nlminb、多起始值重新拟合相同数据和相同约束。14个可进行浓度拟合的化合物均复现了旧拟合，观测点预测值最大差异为0.00002832分，未发现方程实现或数值计算错误。

仅将强度和上下平台同时除以12不会改变曲线的相对形状、斜率位置或EC50。本次数值检验的最大误差为2.22e-16。因此，纵轴改成0-1本身不能解释曲线形状的全部差异。

作为敏感性对照，本次另拟合固定上下平台为0与12的两参数模型：

I(C) = 12 * plogis[s * (log10(C)-log10(EC50))]

将其除以12即可得到上下平台为0与1的归一化响应。这个模型增加了“最低平台为0、最高平台为12”的假设。本次对照只用于解释平台约束对曲线的影响，不声称这是毕设实际使用的方程。

以1-辛烯-3-醇为例，四参数模型的浓度均值RMSE为0.429分，固定平台模型为1.296分；对应的EC50分别约5,932和2,415 ppb。两者的半响应定义随平台假设改变，不能把这两个EC50当作完全相同的感官阈值。

RMSE较低不单独构成选择四参数模型的理由，因为其参数更多。本次同时按浓度级做留一交叉验证；仅有5个浓度级的化合物不报告四参数留一结果，因为删除1级后只有4个浓度点对应4个参数，无法据此稳健判断预测能力。完整结果见tables/model_assumption_audit.csv。

确实需要纠正的是对参数稳定性的解释。旧模型包保存的1,000次品评员自助拟合结果中，以下7个化合物有超过20%的拟合接触至少一个参数边界：2-甲基丁酸乙酯、苯乙醇、苯乙酸乙酯、二甲基三硫、反,顺-2,6-壬二烯醛、己酸乙酯、正丁醇。这表示参数估计受到边界及浓度覆盖限制，不能把这些EC50和稳定估计同等解读，也不能靠高R²消除这一限制。此比例是对旧模型结果的复核，不是本次重新运行的1,000次拟合。

本次将己酸乙酯的斜率上限从10放宽到30，估计斜率增至约21.39，说明旧斜率上限确有约束作用；实际浓度在跃升区覆盖不足，不能用放宽边界换来的更陡曲线作为参数已稳定的证据。

## 图形如何使用

- 01_All15_Intensity_4PL_R：全部单体实测均值、95%均值区间与相同约束下重拟合的4PL曲线。虚线表示旧自助结果中边界接触较多的系列。误差线是均值区间，不是拟合曲线的置信带。
- 02_All15_Observed_Response_R：全部单体的均值和95%区间，连接实测均值，适合在模型尚未定稿时完整呈现数据。
- 03_All15_Model_Comparison_R：同一份数据下的四参数与固定平台两参数对照，纵轴明确为平均评分/12。
- 异丁酸乙酯保留全部C1-C8观测，不强行套用浓度曲线。当前表中C7、C8均对应40,000,000 ppb，但二者的浓度标签关系尚待确认，因此按C级展示，并保留所有原值。

## 雷达图

单体雷达图参照杨泽镔论文PDF第16-18页，每种化合物一个面板，各浓度级用不同颜色和点形表示；16个轴按原始表列名排列，包含“其他”。主版本依照毕设采用不同面板上限，实际刻度已标出；07版本统一上限为1，便于跨化合物比较。数据没有按面板最大值或最小值重新归一化。

混合雷达图参照华铖凯论文PDF第16-19页，每个样品一个面板；15项明确属性构成雷达轴，实线为样品，灰色虚线为R=0.5共同基底。另给六个单高水平配方的大面板预览。全部65个样品均保留，即使不同配方具有相同的属性汇总轮廓，也不合并。

所有雷达图的数值均为属性选择人数/该项有效记录人数，不代表0-12分气味强度。无属性强度评分时，不能将其称作“感官属性强度雷达图”。

## 缺失记录与待核实字段

混合样品仍有1,132/1,170条逐人记录，即38条预期记录待补齐，实际每样15-18人。图中按实际有效人数计算频率并标注n；未将缺失人员视为未勾选。用户补齐18人后，用同一R脚本更新即可。

单体属性中另有1个非二元记号：丁酸C1、S11、“麝香”字段为“.”，位置为“单体数据原始数据!J12”。本次将其作为该属性缺失值，分母为17，其余属性不受影响；没有将“.”擅自改为0。记录见inputs/attribute_entries_to_verify.csv。

原汇总表的26项差异只是可唯一匹配标签的核算结果。重复标签和未能唯一对应的汇总行另留在完整核算CSV中，不自动更改身份、不覆盖原始工作簿。

## 复现

本次均值、频率、品评员重抽样区间、模型复算、交叉验证与图形几何均在真实R中运行完成，版本为R 4.6.0（WebR 0.6.1运行环境）。Python仅用于读取Excel、整理传入R的原始记录、合并PDF和导出PNG；不生成模型曲线或雷达几何。R运行记录见R_run_log.txt及tables/R_sessionInfo.txt。

在本文件夹中运行：`Rscript replot_sensory.R`。只需R自带的stats、graphics、grDevices；字体默认Noto Sans CJK SC。其他系统可先设置`Sys.setenv(SENSORY_FONT="Microsoft YaHei")`等本机可用中文字体。PNG由R生成的矢量PDF直接栅格导出。
