# R感官图与数据（2026-11-23，第1次）

全部15种单体的强度响应、单体属性雷达图，以及65个混合样品雷达图。

- `Sensory_R_Figures_Complete_20261123.pdf`：16页合并矢量图册。
- `Sensory_R_Vector_Source_20261123_v1.zip`：全部独立矢量图、R源代码、统计缓存与编码后的逐人记录。下载并解压即可取得完整目录。
- `replot_sensory.R`：使用R重新计算和绘图；运行前解压图源包。
- `inputs/`、`tables/`：输入记录与计算表。
- `Model_Review_and_Figure_Notes.md`、`Mean_Check_Items.csv`：模型核查说明及汇总均值差异表。

缺失记录未填零，原始Excel未修改。PNG是矢量图的导出格式；图源包以矢量PDF保留所有科学图形。
