## 三种用法

| 你想做什么 | 读哪个 |
|---|---|
| **接手继续做** | `00_会话上下文.md` → 第 3 节（结论）、第 6 节（坑）、第 7 节（复现） |
| **写论文 / 投稿** | `..\英文图注与Methods.md` + `00_会话上下文.md` 第 6 节（未解决问题） |
| **让程序或 AI 接管** | `context.json`（10 个顶层键，结构见下） |

`context.json` 顶层结构：

```
meta            环境与版本
project         任务、对象、目标、约束
data_assets     4 个原始 Excel 的 Sheet 结构与作用
verified_findings  7 个主题的全部已验证数字
decisions       D1–D8 决策与理由
artifacts       图 / 表 / 报告 / 文档清单
open_issues     13 条，按 P0–P3 分级
reproduce       6 步运行顺序与依赖
traps           8 条踩坑速查
next_steps      5 条后续建议
```
