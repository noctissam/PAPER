## 整张图 = 7 个图层

一张能投稿的浓度–响应图，是**从下往上**叠这 7 层。缺任何一层，审稿人都可能挑刺。

```
第7层  文字标注      EC50 / n / R² / CI 数值框
第6层  参考线        EC50 竖虚线 + 半最大水平箭头
第5层  误差棒        点的 SEM 或 SD
第4层  拟合曲线      Hill 拟合实线
第3层  置信带        bootstrap 95% CI 阴影
第2层  原始数据点    ○ 实测均值
第1层  坐标系        对数横轴 + 网格 + 轴标签
```

**顺序很重要**：先画第 2 层看数据形状 → 再拟合 → 再往上叠。
**不要先画曲线再对数据**，那样你永远发现不了模型选错了。

---

## 第 1 层：坐标系（最容易翻车的一层）

### 三个必设项

| 设置 | 做法 | 为什么 |
|---|---|---|
| **X 轴对数** | `双击 X 轴 → 轴类型 → Log10` | 浓度跨 5 个数量级，线性轴会把前 3 个点挤成一团 |
| **禁止科学计数偏移** | 刻度标签不能出现 `0.0001` + 轴角标 `1e+07` | 这是**投稿图最常见的翻车点**，读者要在脑子里做乘法 |
| **主刻度 = 10 的整数次幂** | 每 1/2/3 个数量级一个主刻度 | 次刻度做密网格但不标数字 |

### ✗ 错误示范 vs ✓ 正确示范

```
✗  0.0000.00010.0001...1.0000      ← 标签重叠 + 偏移 1e+07
✓  1        10       100      1000     ← 干净
✓  10      1000      1e+05              ← 跨度大时每 2 个数量级一个
```

### 各软件操作

| 软件 | 操作路径 |
|---|---|
| **GraphPad Prism** | 双击 X 轴 → `Axis` 页 → `Logarithmic scale` 勾选 → `Show numbers as` 选 `Plain numbers` |
| **Origin** | 双击 X 轴 → `Scale` 页 → Type = `Log10` → 取消 `Offset` 那个框 |
| **R (ggplot2)** | `scale_x_log10()` + `labs(x = "Concentration (ppb, log scale)")` |
| **R (drc 自带 plot)** | `plot(fit, log = "x")` |

### 图注写法（照抄）
> Concentration is plotted on a logarithmic scale (base 10). Major ticks denote decades.

## 第 2 层：原始数据点

### 画什么
每个浓度一个点，纵坐标 = 该浓度下所有品评员打分的**均值**。

### 必做：加误差棒
```
误差类型：SEM（均值的标准误）← 描述"均值有多可靠"
          SD              ← 描述"人之间差多少"
          95% CI          ← 最严格，推荐
选择依据：审稿人问"差异显不显著"→ 用 SEM 或 CI
         审稿人问"个体差异大不大"→ 用 SD
```

| 软件 | 操作 |
|---|---|
| Prism | 画 `XY` 图时勾选 `Draw error bars` |
| Origin | 右侧 `Plot Details` → `Error Bars` → 设 Y Error |
| R | `geom_errorbar(aes(ymin=I-SEM, ymax=I+SEM))` |

### 视觉规范
- 点大小 4–5 pt，**白色描边 0.5–0.8 pt**（防止点重叠时糊成一团）
- 颜色：拟合曲线用**红**，数据点用**蓝** → 色盲友好且对比明确
  （推荐色：`#2166AC` 蓝 / `#B2182B` 红，出自 ColorBrewer）

## 第 3 层：95% 置信带 ⭐（区分专业与业余的关键）

### 它是什么
不是"某个具体浓度的不确定度"，而是**整条拟合曲线的不确定度范围**。

### 怎么算（Bootstrap）
```
重复 2000 次：
  ① 以「品评员」为单位有放回重抽
     （⚠️ 不是重抽均值！是回到原始逐人数据重抽）
  ② 用重抽后的数据重新算均值
  ③ 用新均值重新拟合 Hill 方程
  ④ 记录这次的 EC50 和 n
取 2.5% 和 97.5% 分位数 → 95% CI
对每个浓度点，纵向的 2.5%/97.5% 分位数连成带 = 置信带
```

### 各软件做法

| 软件 | 怎么做 |
|---|---|
| **Prism** | ❌ 做不到，需导出到别处算（这是 Prism 最大的短板） |
| **Origin** | 有内置 bootstrap，需手动设置迭代次数 |
| **R + drc** | `msu::msuBoot()` 或自己写循环；包 `boot` 也可 |
| **Python** | `scipy.optimize.curve_fit` + 手写 for 循环（示范图就是这么做的） |

### 为什么必须画
没有置信带 → 读者无法判断曲线在低浓度端是不是纯属外推。
**审稿人最常见的提问**："Can the authors provide confidence intervals for the fitted parameters?"

## 第 4 层：拟合曲线

### 方程
```
R = R₀ + (R_max − R₀) · Cⁿ / (EC50ⁿ + Cⁿ)
      ↑         ↑          ↑
    下平台    上平台     半最大浓度
```

### 拟合方式（三种，结果略有不同）

| 方式 | 做法 | 优缺点 |
|---|---|---|
| **非线性最小二乘**（直接拟合 Y） | `curve_fit(f, C, I)` | ✅ **推荐**。Chastrette 1998 明确指出：直接拟合实验值可避免线性化偏差 |
| 先转 log 再线性回归 | `log(I) ~ log(C)` | ⚠️ 会对低浓度点过度加权，参数有系统偏差 |
| 手动读图 | 目测拐点 | ❌ 绝对不可用于投稿 |

### 拟合前的"体检"三问

```
❓ Q1 曲线上平台走平了吗？
        没走平 → Imax 是外推值 → EC50 的 CI 会极宽 → 慎报
❓ Q2 拐点在实测浓度范围之内吗？
        不在 → Hill 参数不可信（Chastrette 1998）→ 改用 Stevens 幂律
❓ Q3 残差图是随机散布吗？
        呈喇叭形/弯曲 → 模型不对 → 换 Weibull 或分段
```

> 📌 你论文的问题正是在 Q2：
> 图3 里 1-辛烯-3-醇 的实测浓度是 2 ~ 2×10⁵ ppb，
> 但标注的 Kd = 18.15 ppb 落在**最左边**，
> 而曲线的真实拐点在 ~6×10³ ppb（中间偏右）。
> **标注值和曲线不在一个位置** —— 这就是 EC50 标注错误。

## 第 5 层：EC50 参考线

### 两根线一起画
```
   │                    ╭───── R_max
   │              ╭─────╯
   │ ← 这条水平虚线 = (R_max − R₀)/2，箭头指向曲线交点
   │ ─ ─ ─ ─ ─ ─ ─ ─ ● ← 交点 = 半最大点
   │              ╭─╯
   │ ╭────╮
   └─│────┼─────────────────→ log C
     │   EC50 竖虚线
```

### 为什么这么画
因为 **EC50 ≠ Y=50**。
GraphPad 官方文档专门警告过这点：
> "EC50 is the concentration of agonist that gives a response half way between Bottom and Top.
> **This is not the same as the response at Y = 50.**"

你的量表是 0–12，如果 R₀=2.4、R_max=11，那半最大点是 **6.7 分**，不是 6 分。
**审稿人如果按 Y=50 读你的图，会读错。**

## 第 6 层：数值标注框

### 单面板（demo_single_panel）
```
右上角：Imax = 10.98
        n = 1.712  [1.26–2.49]      ← 带 CI
        R² = 0.9867
拐点旁：EC50 = 5931 ppb
        (95% CI 4275–8192)
```

### 多面板拼图（demo_small_multiples）
空间有限，**只放 3 个关键数字**：
```
左上角：n = 1.71
        R² = 0.987
右下角：EC50
        5.9e+03        ← 科学计数格式（窄面板必须这么写）
```

### ⚠️ 排版规范
| 项目 | 要求 |
|---|---|
| 字号 | ≥ 6 pt（小面板）/ ≥ 8 pt（单面板），**印刷后不能小于 7 pt** |
| 颜色 | 与所标注元素同色（EC50 用红色） |
| 背景框 | 白/浅灰 + 细边框，`framealpha=0.9`，**不要遮挡数据点** |
| 格式 | 数值有效位数与数据量级匹配（`%.2f` → `%.3g` → `%.2g`） |

## 第 7 层：投稿导出

| 要求 | 设置 |
|---|---|
| **格式** | 优先 PDF/SVG（矢量）；期刊若要位图则 300–600 dpi |
| **尺寸** | 按最终印刷宽度设计：单栏 85 mm，双栏 180 mm |
| **字号** | 按**最终尺寸**设计字号，缩小后仍 ≥ 7 pt |
| **字体** | Arial / Helvetica / Times；PDF 必须嵌入（Type 42） |
| **背景** | 白底（很多期刊要白底，Prism 默认灰底要改） |
| **数据可得性** | 很多期刊要求提供原始数据文件 |

### Prism 导出路径
`File → Export Image` → 选 `PDF` 或 `TIFF` → 勾选 `300 dpi` →
**取消 `Transparent background`** → 确认 `800 dpi` 时的实际尺寸符合期刊要求

## 🅰️ 单面板完整制作流程（Prism，最快）

```
Step 1  New Table & Graph → XY (Scatter)
Step 2  每列一个浓度组：X 填 log10(浓度)，Y 填强度均值
        ⚠️ 15 个化合物做 15 张，或建 "Grouped" 子数据表
Step 3  勾选第二 Y 轴栏放 SEM
Step 4  Analyze → Nonlinear regression → Dose-response - Stimulation
        → "log(Agonist) vs. response -- Variable slope"  (= 4PL / Hill)
Step 5  拟合完 → 点 "Insert" → 新建 Graph
        → Graph 里会自动画出曲线
Step 6  Graph 上右键 → Add Text 标注 EC50、n、R²
Step 7  双击 X 轴 → Log10 + Plain numbers（关键！）
Step 8  File → Export Image → PDF → 300 dpi → 白底
```

**⚠️ Prism 做不到置信带** → 置信带必须在别处算好后用 PowerPoint/Illustrator 叠加。
这是 Prism 的**硬伤**，也是推荐 R 的主要原因。

## 🅱️ 单面板完整制作流程（R + drc，推荐）

```r
library(drc); library(ggplot2)

# 1) 拟合
fit <- drm(intensity ~ log10(conc_ppb), data = df,
           fct = LL.4(names = c("n","Rmin","Rmax","logEC50")))
summary(fit)
ED(fit, resp = c(10,50,90))          # 反解 EC10 / EC50 / EC90

# 2) Bootstrap（置信带）
set.seed(1)
grid <- seq(min(df$conc_ppb)*0.6, max(df$conc_ppb)*2.5, length.out = 400)
B <- replicate(2000, {
  d2 <- df[sample(nrow(df), replace = TRUE), ]
  f <- drm(intensity ~ log10(conc_ppb), data = d2, fct = LL.4())
  as.numeric(predict(f, grid))
})
band <- apply(B, 1, quantile, probs = c(0.025, 0.975))

# 3) 出图（7 层一次性叠好）
co <- as.data.frame(fit$curve[, 2:5])
ggplot(df, aes(conc_ppb, intensity)) +
  geom_ribbon(data = co, aes(x = conc_ppb, ymin = band[,1], ymax = band[,2]),
              fill = "#F4A6A6", alpha = .45) +          # 第3层 置信带
  geom_line(data = co, aes(x = conc_ppb, y = fitted),
            colour = "#B2182B", linewidth = .8) +       # 第4层 拟合曲线
  geom_errorbar(aes(ymin = intensity-SEM, ymax = intensity+SEM),
                width = .1, linewidth = .4, colour = "#2166AC") +  # 第5层
  geom_point(colour = "#2166AC", size = 2.4, shape = 21,
             fill = "#2166AC", stroke = .4) +            # 第2层 数据点
  geom_vline(xintercept = 10^coef(fit)[4], linetype = "dashed",
             colour = "#555555", linewidth = .4) +       # 第6层 EC50线
  annotate("text", x = 10^coef(fit)[4], y = Inf,
           label = sprintf("$EC_{50}$ = %.0f ppb", 10^coef(fit)[4]),
           vjust = 1.8, hjust = 0, size = 3, colour = "#B2182B") +
  scale_x_log10() +
  labs(x = "Concentration (ppb, log scale)",
       y = "Perceived odour intensity (0–12)",
       title = df$compound[1]) +
  theme_classic(base_size = 10)
```

## 🅲 多面板拼图（你 15 个化合物需要这个）

### 关键点
1. **必须共享坐标轴** —— 否则读者无法横向比较谁的曲线更靠左
2. **颜色统一** —— 蓝点红线贯穿全部面板，不要每格换色
3. **布局按 EC50 排序** —— 从左到右、从强到弱，规律一眼可见
4. **空白格隐藏** —— 15 个排 5×3，用 `set_visible(FALSE)` 藏掉空位

### 三种排法

| 排法 | 适合 |
|---|---|
| 按化合物名（字母序） | 需要按类别讨论时 |
| **按 EC50 排序** | ✅ 突出"谁最强"，视觉冲击最强 |
| 按化学类别（酯/醇/醛…） | 需要讨论结构-活性关系时 |

> 示范图用的是 **EC50 排序**（二甲基三硫 8.9 ppb → 苯乙醇 8×10⁷ ppb，横跨 7 个数量级）。
> 这张图一眼就能看出：**浓度跨度必须逐个化合物单独设计，不可能用一套浓度做所有化合物**。
> 这本身就是你论文值得写一句 discussion 的点。

## 🌲 森林图（EC50 排序 + CI）

```
横轴 log；纵轴化合物名（倒序）；点 + 误差棒 = EC50 ± 95% CI
```

**为什么单独出这张图**：
- 15 个曲线图看的人会累，森林图**3 秒给出全局排序**
- CI 区间宽度直接暴露**哪些化合物的估计不可靠**（区间跨几个数量级 = 不该报）
- 是审稿人判断"你的结论稳不稳"的第一眼

**读法**：
> 你的数据里 **乙酸乙酯** EC50 = 4.4×10⁴ ppb 但 95% CI 极宽（因为它的曲线是"突然跃升"型，拐点定位困难）
> **正丁醇** 只有 4 个浓度点且**完全没有原始逐人数据**（之前核查发现）→ EC50 不可靠
> 这两个化合物**必须在论文里说明数据不足**，或者干脆不报 EC50。

## ✅ 投稿前逐条自检

- [ ] X 轴 log，**刻度无科学计数偏移、无标签重叠**
- [ ] 数据点带误差棒，注明 SEM/SD/CI
- [ ] 拟合曲线是**非线性直接拟合**，不是 log-log 线性化

- [ ] 图注含：模型名称、EC50 定义、CI 算法、品评员人数、n 点数

- [ ] 数据点不足 / CI 极宽的化合物已说明或剔除
