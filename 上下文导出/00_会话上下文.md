### 3.2 R 值溯源 🟢

采用**像素数字化**：蓝点做 y 轴标定（锚定 Excel 强度均值）、网格线做 x 轴标定（41.08 px/十进制度，1e+06 → x=397，1e+10 → x=561），再读红曲线。

| 检查项 | 判定 | 证据 |
|---|---|---|
| `R = 强度均值 ÷ 12` | ✅ 正确 | R² = 0.99999 |
| 模型 = Hill `R = Cⁿ/(Kdⁿ + Cⁿ)` | ✅ 正确 | R² = 0.9998 |
| `n` 能否反解 | ✅ 可以 | 差 3–7% |
| **Kd / EC₅₀ 与所画曲线** | ❌ **不对应** | 差 **51× / 639× / 15 万×**，倍数**不恒定** |

**结论**：`Kd` 极可能**取自图之外的来源**（阈值实验或文献），不是本图拟合所得。在 log 轴上 Kd 与 n 是两个独立自由度，**无法从曲线反推 Kd**。

### 3.3 剂量–响应模型 🟢（本次新验证）

原拟合脚本已丢失，因此我们做了**模型指认实验**：

| 候选模型 | 与存档参数的一致性 | 判定 |
|---|---|---|
| 3 参数 Hill（下渐近线固定为 0） | EC₅₀ 倍数中位 **810**，0/15 吻合 | ❌ 错误 |
| **4 参数 log-logistic（自由下渐近线）** | **R² 15/15 完全一致**；Iₘₐₓ 14/15、n 14/15、EC₅₀ 10/15 在 10% 内 | ✅ **确认** |

$$
I(C) = d + (I_{\max}-d)\,\frac{C^{n}}{EC_{50}^{n}+C^{n}}
$$

**关键佐证**：EC₅₀ 复现失败的那 5 个化合物（二甲基三硫、反顺壬二烯醛、苯乙酸乙酯、异丁酸乙酯、苯乙醇）**恰好就是低 *n*（< 0.6）的平坦曲线**，其置信区间退化或跨度超过一个数量级 —— 属**结构性不可辨识**，不是精度问题。

**参数概览**

| 项目 | 数值 |
|---|---|
| EC₅₀ 范围 | 8.88 ~ 7.98×10⁷ ppb（≈ 900 万倍） |
| R² 范围 | 0.950 ~ 1.000 |
| **Iₘₐₓ > 12（量表上限）** | 5 个：苯乙醇 19.83、苯乙酸乙酯 13.87、反顺壬二烯醛 12.72、二甲基三硫 12.71、异丁酸乙酯 12.70 |
| **饱和拟合** | 丁酸：4 点拟合 4 参数，R² = 1.000，自由度 = 0 |
| **n 的 CI 宽度为 0** | 二甲基三硫 0.292、反顺壬二烯醛 0.4895、正丁醇 1.2554 |
| **EC₅₀ CI 跨度示例** | 2-甲基丁酸乙酯 1,648–398,920（**242×**）；苯乙醇 10×；己酸乙酯 9.6× |

### 3.5 混合物加和性 🟢（有边界条件）

**设计**：15 组二元混合 × 15 个 CATA 属性 = **225 个配对预测**

**预测式**：`p̂ = clip[0,1]{ p₀ + (p_A − p₀) + (p_B − p₀) }`

| 指标 | 数值 |
|---|---|
| Pearson r | **0.812**（p = 6.02×10⁻⁵⁴） |
| RMSE | 0.0998 |
| 平均偏差 | +0.0157（几乎无系统偏移） |
| 平均绝对偏差 | 0.0669 |

**属性级偏差**

| 方向 | 属性（数值 = 实测 − 预测） |
|---|---|
| **协同/增强**（红） | 甜香 **+0.0683**、青草 **+0.0676**、麝香 **+0.0646**、水果 **+0.0615** |
| **掩蔽/减弱**（蓝） | 花香 **−0.0371**、化学试剂 **−0.0321**、烘烤 **−0.0196**、清凉 **−0.0151** |

> **边界条件（必须写进论文）**：酸味的 sd = 0.2577，是其他属性的 3–5 倍，其误差棒最长，**实际不显著**。
> 且混合物**没有强度数据**，所以本文只能说"**属性勾选频率**大体加和"，**不能**说强度加和，**不能**等同 isobologram 或 σ–τ。

### 3.6 双峰性 → **负结果** 🟢

假设：是否存在"敏感者 / 不敏感者"两类人群。**结论：不支持。**

| 检验 | 结果 | 解读 |
|---|---|---|
| Silhouette（k=2–6，两种特征集） | **0.109 – 0.153** | ≪ 0.5 → **无可靠簇结构** |
| GMM 组分数（18 人全局均值） | BIC(k=1) = **23.93** < BIC(k=2) = 31.47<br>ΔBIC = BIC(1)−BIC(2) = **−7.54** | 支持**单组分** |
| 全局均值分布范围 | 5.41 – 6.95（sd 0.41） | 量程占比极小，天然难分群 |
| 逐浓度点 ΔBIC > 10 | **38 / 87（44%）** | 但 7 个天花板点 7/7 全中 → 大半是假象 |
| **5 条严格判据后** | **1 / 87（1%）** | 仅剩 1 个 |

**严格判据与淘汰路径**

1. ΔBIC > 10 → 38 个
2. 小组分权重 0.20–0.80 → 剩 **22**
3. 两组分均值差 ≥ 3 量表单位 → 剩 15
4. 该点均值 3–9（远离地板 0 与天花板 12）→ 剩 **9**
5. 两组分之间存在跨度 ≥ 3 的空档 → 剩 **3**
6. 五条全过 → **1**

**唯一幸存者：异丁酸乙酯 C6**

- mean = 6.056，sd = 2.413，ΔBIC = **+81.32**
- 两组分均值差 4.4，空档跨度 3（6 → 9，中间 7/8 全空）
- 18 个原始值：`6,6,4,9,9,9,5,9,2,5,6,9,4,5,5,9,2,5`

**k-means 参考**：k=3，簇规模 5 / 8 / 5，全局均值 6.60 / 5.89 / 6.06。
⚠️ 簇是由同一批强度变量构造的，**簇间 t 检验属循环论证**，不构成独立证据（脚本里已打警告，图里未报 p 值）。
